# Decisions

Measured design decisions, one file per topic, each with the numbers, the machine and the commit. The TDD names which milestone writes which file: `renderer.md` at M2, `conpty.md` at M1. `throughput.md` (M1, task-2459) sets the P1 gate file and number from a comparison against Ghostty 1.4 and alacritty_terminal on the same bytes. `parser.md` (M1) records the parser choice. `renderer.md` (M2) records R4, P2 and the start up measurements behind the renderer choice. `fonts.md` (M3) is the Windows font fallback matrix. `startup.md` (M3, task-2462) sets where the P4 interval ends and what the probe reports per platform. `efficiency.md` (task-2481) compares memory and CPU with Ghostty on Windows with `termoil-bench apps`, and records why the window now draws with `RasterRenderer` and how each change was measured. `detach.md` (M4, task-2463) reads the PRD 5.3 row "a window can be detached to its own process" and specifies `termoil-gui --separate`; it is a design reading, not a measurement. `updates.md` (task-2524) is the nightly and stable channels, the update check and installing an update; also a design reading. `telemetry.md` (task-2530) is the anonymous usage statistics for Termoil, Chordical and the Chordical Synthesizer, sent to Google Analytics; a design reading. `window-actions.md` (task-2586) is how an action run from the palette or a key is run and its answer or failure shown, and the A5 tests that check every action from the window.
