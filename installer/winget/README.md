# winget manifest

`tools/release.ps1` runs `Write-WingetManifest` after the GitHub release is created and verified. It writes three files to
`installer/winget/manifests/t/Terminus/Terminus/<version>/`: the version file, the default locale file and the installer file
(manifest schema 1.10.0). The package identifier is `Terminus.Terminus`, which is the AppUserModelID in
`installer/windows/terminus.iss`. The installer URL is the `TerminusSetup-<version>-x64.exe` asset on the release, and the
SHA256 is the hash of the local installer, which the script has already compared with the downloaded asset.

The script writes the files and does not commit them or open a pull request. The manifest for v0.1.1 was generated by calling the
function with that release's URL and hash.

## Check a manifest

    winget validate --manifest installer/winget/manifests/t/Terminus/Terminus/<version>

Installing from a local manifest needs an administrator to run `winget settings --enable LocalManifestFiles` once.

## Publish to the winget catalogue

This opens a public pull request on microsoft/winget-pkgs from your GitHub account, so a person does it.

Using wingetcreate (`winget install Microsoft.WingetCreate`), with a personal access token that has the `public_repo` scope:

    wingetcreate submit --token <token> installer/winget/manifests/t/Terminus/Terminus/<version>

Or by hand:

1. Fork https://github.com/microsoft/winget-pkgs.
2. Copy `installer/winget/manifests/t/Terminus/Terminus/<version>` to `manifests/t/Terminus/Terminus/<version>` in the fork.
3. Commit it on a branch named `Terminus.Terminus-<version>` with the message `New package: Terminus.Terminus version <version>`
   for the first release, or `New version: Terminus.Terminus version <version>` after that.
4. Open a pull request against `master` and wait for the validation pipeline to pass.

The release must be published as a full release (`-Stable`) before the first submission is useful, because winget-pkgs reviewers
test the installer URL and a prerelease is marked as such on GitHub. v0.1.1 is currently a prerelease.
