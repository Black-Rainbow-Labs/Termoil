# Decisions

Measured design decisions, one file per topic, each with the numbers, the machine and the commit. The TDD names which milestone writes which file: `renderer.md` at M2, `conpty.md` at M1. `throughput.md` (M1, task-2459) sets the P1 gate file and number from a comparison against Ghostty 1.4 and alacritty_terminal on the same bytes. `parser.md` (M1) records the parser choice. `renderer.md` (M2) records R4, P2 and the start up measurements behind the renderer choice. `fonts.md` (M3) is the Windows font fallback matrix.
